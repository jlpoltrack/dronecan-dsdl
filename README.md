# dronecan-dsdl

C serialisers generated by [dronecan_dsdlc](https://github.com/dronecan/dronecan_dsdlc) for a subset of the [DroneCAN DSDL](https://github.com/dronecan/DSDL), packaged as a PlatformIO library. They need [libcanard](https://github.com/dronecan/libcanard) (`canard.h`) on the include path, e.g. from the project's own `lib_deps`.

Messages:

- `uavcan.protocol.NodeStatus`, `GetNodeInfo` (with `HardwareVersion`, `SoftwareVersion`)
- `uavcan.protocol.file.BeginFirmwareUpdate`, `Read` (with `Path`, `Error`)
- `uavcan.tunnel.Targetted` (with `Protocol`)
- `dronecan.sensors.rc.RCInput`

Encoders take a `tao` argument and decoders follow `transfer->tao`, so the same files serve CAN 2.0 and CAN FD (`CANARD_ENABLE_CANFD`): pass `tao = !canfd` when encoding.

## Generated from

- DSDL `b4653c7abc3c47cb31b16efa24ea755232774756`, newer than ArduPilot's submodule, adds the RCInput `QUALITY_TYPE` constants
- dronecan_dsdlc `de47a8972b7d8c59e50c3acfab5754db29798caa`

Local headers use quoted includes, so they resolve from this library's folder.

## Regenerating

`tools/regenerate.sh` clones both at those commits into a scratch folder, runs the generator and refreshes the files already in `src/`. To add a message, copy its `.c`/`.h` and those of the types it depends on into `src/` first.

## PlatformIO

```ini
lib_deps = https://github.com/jlpoltrack/dronecan-dsdl.git#<commit>
```
